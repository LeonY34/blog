P9035 「KDOI-04」Pont des souvenirs

题意

给定正整数 n,kn,kn,k，求有多少个长度为 nnn 的正整数序列 aaa 满足：

  • 0<a1≤a2≤a3≤⋯≤an≤k0<a_1\le a_2\le a_3\le\cdots\le a_n\le k0<a1​≤a2​≤a3​≤⋯≤an​≤k；
  • ∀ i≠j\forall\ i\not=j∀ i=j，ai+aj≤k+1a_i+a_j\le k+1ai​+aj​≤k+1。

题解

首先发现第二个条件实际上不是很强，因为 {a}\{a\}{a} 是单调不降的，所以只需满足 an−1+an≤ka_{n-1} + a_{n} \leq kan−1​+an​≤k 就好了。

而第一个条件很像一个组合数能算的东西。那么我们不妨定义 f(x,y)f(x,y)f(x,y) 表示满足 0<a1≤a2≤a3≤⋯≤ax≤y0<a_1\le a_2\le a_3\le\cdots\le a_x\le y0<a1​≤a2​≤a3​≤⋯≤ax​≤y 的数列个数。由于第二个条件只作用于最后两个数，我们不妨枚举 ana_nan​。当 an=xa_n=xan​=x 时，有 an−1≤k+1−xa_{n-1}\leq k+1-xan−1​≤k+1−x 和 an−1≤xa_{n-1}\leq xan−1​≤x 同时成立，那么答案为：

∑x=1kf(n−1,min⁡{x,k−x+1})\sum_{x=1}^{k} f(n-1,\min\{x,k-x+1\}) x=1∑k​f(n−1,min{x,k−x+1})

观察式子发现，函数的第二维是先递增再递减的。我们不妨把它拆开。当 kkk 为奇数时：

∑x=1k+12f(n−1,x)   +∑x=1k−12f(n−1,x)\sum_{x=1}^{\frac{k+1}{2}} f(n-1,x)\ \ \ +\sum_{x=1}^{\frac{k-1}{2}} f(n-1,x) x=1∑2k+1​​f(n−1,x)   +x=1∑2k−1​​f(n−1,x)

当 kkk 为偶数时：

2⋅∑x=1k2f(n−1,x)2\cdot\sum_{x=1}^{\frac{k}{2}} f(n-1,x) 2⋅x=1∑2k​​f(n−1,x)

接下来考虑如何求得 f(x,y)f(x,y)f(x,y)。

首先有一个非常明显的递推式：我们依然枚举最后一位，那么前面 x−1x-1x−1 位是随便选的，就得出了：

f(x,y)=∑i=1yf(x−1,i)f(x,y) = \sum_{i=1}^{y} f(x-1,i) f(x,y)=i=1∑y​f(x−1,i)

这个式子看起来一点用都没有，但实际上它可以优化之前我们得出的答案式子。答案就变为了，kkk 为奇数时：

f(n,k+12)+f(n,k−12)f(n,\frac{k+1}{2})+f(n,\frac{k-1}{2}) f(n,2k+1​)+f(n,2k−1​)

kkk 为偶数时：

2⋅f(n,k2)2\cdot f(n, \frac{k}{2}) 2⋅f(n,2k​)

这下看起来简洁多了。由于第一个条件十分简洁，我们不妨考虑用组合数直接求出 f(x,y)f(x,y)f(x,y)。

由于数列是单调不下降的，前面的数的选择会影响到后面的数的选择。这很不方便。于是我们采取一个常见的套路：把问题转化为一开始有 xxx 个 111，有 y−1y-1y−1 次 +1+1+1 的机会（原先已经有 111 了），每次可以选择一个数，让这个数和后面所有数都 +1+1+1。然而特殊地，我们可以不用完所有机会，于是把浪费掉的 +1+1+1 机会定义为给 x+1x+1x+1 个数 +1+1+1。（同样的，我们也可以借助差分的思想，把原数列差分后转化为给 y−1y-1y−1 个差分数组里的数 +1+1+1。）

无论如何，现在我们将问题转化为了插板法的模型：把 +1+1+1 看作板，数看作球，那么就转化为了在 x+1x+1x+1 个空隙中插入 y−1y-1y−1 块板，可以在同一空隙插入多块板。那么我们不妨再增加 y−2y-2y−2 个空隙，那么就成了 x+y−1x+y-1x+y−1 个空隙插入 y−1y-1y−1 块板，答案是 Cx+y−1y−1C_{x+y-1}^{y-1}Cx+y−1y−1​。（如果你交换板和球，也将得到同样的答案）

或者说更加直观一点，我们把 +1+1+1 也看成是数，那么就是合并一个有 xxx 个元素的数组和有 y−1y-1y−1 个元素的数组，每个数组中的元素相同（111 和 +1+1+1），两个数组之间的元素不相同。很显然，最后得到的数组有 x+y−1x+y-1x+y−1 个元素，其中要选 xxx 个 111（或者选 y−1y-1y−1 个 +1+1+1 ），答案是 Cx+y−1y−1C_{x+y-1}^{y-1}Cx+y−1y−1​。

我们也可以通过变形 f(x,y)f(x,y)f(x,y) 的递推式，得出 f(x,y)=f(x−1,y)+f(x,y−1)f(x,y) = f(x-1,y) + f(x,y-1)f(x,y)=f(x−1,y)+f(x,y−1)，和组合数的递推式进行对比得出通式。

多种方法殊途同归，最后我们得出 f(x,y)=Cx+y−1y−1f(x,y) = C_{x+y-1}^{y-1}f(x,y)=Cx+y−1y−1​。可以 O(n)O(n)O(n) 预处理 O(1)O(1)O(1) 回答。
