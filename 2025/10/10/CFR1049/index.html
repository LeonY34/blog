A. Shift Sort

Solution

任意一个三元01串一定有两个连续的数（或者头尾）顺序是对的，只要把这两个数捆绑与第三个数排序即可，用一次leftshift或者rightshift一定可以完成。所以每次操作相当于任取三个数并排序。

我们知道最终的序列，所以我们知道有哪些0和1的位置是不对的，且0的不对的数量和1是一样的。在最优的解法下，每次可以交换一个不对的0和一个不对的1（剩下一个随便取）。所以答案就是不对的个数。

B. Another Divisibility Problem

Solution

先观察x#yx\#yx#y的表达式：

x#y=x×10b+yx\#y = x\times 10^b + yx#y=x×10b+y，其中bbb表示yyy十进制下的位数。

观察到：

x#yx+y=x×10b+yx+y=x×(10b−1)x+y+1\begin{aligned}\frac{x\#y}{x+y} &= \frac{x\times 10^b + y}{x + y}\\ &= \frac{x\times (10^b - 1)}{x + y} + 1\\ \end{aligned}x+yx#y​​=x+yx×10b+y​=x+yx×(10b−1)​+1​

这里有很多种方法，比如说y=8xy=8xy=8x或者题解的y=2xy=2xy=2x。我的解法是y=109−1−xy=10^9 - 1-xy=109−1−x，这样可以保证yyy有九位数，并且底下就是109−110^9 - 1109−1，和上面右半边消掉。

C. Ultimate Value

Solution

首先可以发现Bob纯坐牢，因为他不管干什么Alice都可以跟他干一样的事情，导致他不仅白干，cost还会增加，所以Bob会立马结束游戏。

Alice交换一次，分为三种情况：

  1. 交换奇数iii和偶数jjj（i<ji<ji<j），则答案增量为(aj−ai)×2+j−i=2aj+j−(2ai+i)(a_j - a_i)\times 2 + j - i = 2a_j + j - (2a_i + i)(aj​−ai​)×2+j−i=2aj​+j−(2ai​+i)；
  2. 交换偶数iii和奇数jjj（i<ji<ji<j），则答案增量为(ai−aj)×2+j−i=2ai−i−(2aj−j)(a_i - a_j)\times 2 + j - i = 2a_i - i - (2a_j - j)(ai​−aj​)×2+j−i=2ai​−i−(2aj​−j)；
  3. 交换奇偶性相同的iii和jjj，答案增量为∣i−j∣\left|i-j\right|∣i−j∣。

第三种情况直接头尾两个奇数即可；第一种和第二种分别按照2ai+i,2ai−i2a_i+i,2a_i-i2ai​+i,2ai​−i分别找出奇偶的最大最小值即可。

D. A Cruel Segment’s Thesis

Solution

对于[li,ri][l_i, r_i][li​,ri​]和[lj,rj][l_j, r_j][lj​,rj​]产生的线段，当然是取[li,rj][l_i, r_j][li​,rj​]或者[lj,ri][l_j, r_i][lj​,ri​]。

计算两种方案的长度差：rj−li−(ri−lj)=rj+lj−(li+ri)r_j - l_i - (r_i - l_j) = r_j + l_j - (l_i + r_i)rj​−li​−(ri​−lj​)=rj​+lj​−(li​+ri​)。所以l+rl+rl+r越大的线段，当右端点更划算。

最终的答案只和每个线段当右端点还是左端点还是空着有关，和具体谁和谁mark没有关系，所以我们自然可以先按照l+rl+rl+r排序，大的一半作为右端点，小的一半作为左端点。对于奇数的情况，枚举一下抛弃的线段就好了。

n≤20n\leq 20n≤20，看起来可以状态压缩。

令f[i][j][0/1]f[i][j][0/1]f[i][j][0/1]表示有iii个pile，各个pile的状态压缩为jjj（其中jjj的二进制位为000表示pile有一个数，为111表示pile有两个数），轮到Alice/Bob的最终答案−1-1−1（如果答案是111就是000，答案是222就是111）。可以O(n×2n)O(n\times 2^n)O(n×2n)完成dp（虽然转移是O(n)O(n)O(n)的，但是根据等差乘等比的求和公式，最后答案是n×2nn\times 2^nn×2n左右）。

Solution

此时mmm显得有点大，我们可以定一个中间点0≤p<m0\leq p< m0≤p<m，把小于等于ppp的pile分成一组，把大于ppp的pile分成另外一组。则f[i][j][0/1]f[i][j][0/1]f[i][j][0/1]表示有iii个pile，各个pile的状态压缩为jjj，轮到Alice/Bob的最终答案在第一组/第二组。

我们先统计有xxx个第一组和n−xn-xn−x个第二组的放置方案的f[n][j][0]f[n][j][0]f[n][j][0]总和cnt[x]cnt[x]cnt[x]。

枚举所有ppp和xxx，这样的总情况数为px×(m−p)n−xp^x\times (m - p)^{n - x}px×(m−p)n−x，此时答案增加cnt[n−x]×px×(m−p)n−xcnt[n-x]\times p^x\times (m - p)^{n - x}cnt[n−x]×px×(m−p)n−x。

这个方法的正确性如下：对于每一种可能情况，都会在p=0,1,⋯ ,m−1p=0, 1, \cdots, m - 1p=0,1,⋯,m−1以及对应的分组xxx被统计一遍。假设该情况的答案为yyy，则在p=0,1,⋯ ,y−1p=0, 1, \cdots, y - 1p=0,1,⋯,y−1时每次都会让答案+1+1+1，而在p=y,y+1,⋯m−1p=y, y + 1, \cdots m - 1p=y,y+1,⋯m−1时不会对答案产生贡献。所以这个方法把每个情况都拆到了不同的分类中去统计，是正确的。

F. Sum Minimisation

Solution

首先需要看清楚题目：decrease the yyy smallest values by 111，意思是前yyy小的数都减111。

先将数组排序，不影响答案。

n=1n=1n=1时，直接输出a1a_1a1​；

n=2n=2n=2时，直接输出a1+a2−[(a1+a2)%2=0]a_1+a_2 - [(a_1+a_2)\%2=0]a1​+a2​−[(a1​+a2​)%2=0]

接下来讨论n≥3n\geq 3n≥3的情况。

首先发现，如果选ppp个数2≤p≤n−12\leq p\leq n-12≤p≤n−1不能下降，其充要条件是所有数模ppp都相等（可以通过交换两个数证明）。

c1. 如果a2,a3,⋯ ,ana_2, a_3, \cdots, a_na2​,a3​,⋯,an​中有一个奇数和一个偶数，就可以通过{a1,ai},{a1,aj}\{a_1, a_i\},\{a_1,a_j\}{a1​,ai​},{a1​,aj​}的方式来做到无限下降a1a_1a1​。这个称为情况1。

c2. 如果a2,a3,⋯ ,ana_2, a_3, \cdots, a_na2​,a3​,⋯,an​奇偶性相同，那么我们通过比较模lcm⁡(1,2,⋯ ,n−2)\operatorname{lcm}(1, 2, \cdots, n - 2)lcm(1,2,⋯,n−2)来判断a2,a3,⋯ ,ana_2, a_3, \cdots, a_na2​,a3​,⋯,an​能否取2,3,⋯ ,n−22, 3, \cdots, n-22,3,⋯,n−2个数来发生一次下降。再通过加和来判断能否取a2,a3,⋯ ,ana_2, a_3, \cdots, a_na2​,a3​,⋯,an​来完成一次下降。如果可以，分为两种情况：

  1. 下降超过一个数，或者下降一个数且下降完不小于a1a_1a1​，那么必定出现情况1（最大数不可能下降）；
  2. 下降只有一个数，且下降完小于a1a_1a1​，则交换a1a_1a1​和这个数，再下降一次，必定出现情况1。

至此，证明了c2情况可以归为情况1。

c3. 如果不可以通过a2,⋯ ,ana_2, \cdots, a_na2​,⋯,an​完成下降，则分为四种情况：

  1. a1a_1a1​加入可以使a2,⋯ ,ana_2, \cdots, a_na2​,⋯,an​中的一个数发生下降，则a1a_1a1​依然是最小，得到情况1；
  2. a1a_1a1​加入都不能产生下降，游戏结束，输出∑i=1nai\sum_{i = 1}^n a_i∑i=1n​ai​；
  3. a1a_1a1​加入的任意一种方法都只能使a1a_1a1​下降，下降完游戏结束，输出∑i=1nai−1\sum_{i = 1}^n a_i - 1∑i=1n​ai​−1；
  4. a1a_1a1​加入存在一种方法能使a1a_1a1​下降，也存在一种方法下降不了，则a1a_1a1​起码可以下降两次，并且下降一次或者下降两次后，一定可以让{a1,a2,⋯ ,an}\{a_1, a_2, \cdots, a_n\}{a1​,a2​,⋯,an​}发生一次n−1n-1n−1个数的下降，也就是可以让a2,⋯ ,ana_2, \cdots, a_na2​,⋯,an​中的一个数下降，得到情况1。

具体实现可以按照这个方法分类讨论，也可以直接让a1a_1a1​下降一次，如果还能下降第二次，则输出−1-1−1（因为要么无限下降，要么a1a_1a1​下降一次，要么完全动不了）。
