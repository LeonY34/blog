Solution

首先，注意到对于两个数ai,aja_i, a_jai​,aj​，mmm的最大值为∣ai−aj∣\left|a_i - a_j\right|∣ai​−aj​∣，且可以取到。

对于ai,ai+1,⋯ ,aja_i, a_{i + 1}, \cdots, a_jai​,ai+1​,⋯,aj​，mmm的最大值为gcd⁡(∣ai−ai+1∣,⋯ ,∣aj−1−aj∣)\gcd(\left|a_i - a_{i + 1}\right|, \cdots, \left|a_{j - 1} - a_j\right|)gcd(∣ai​−ai+1​∣,⋯,∣aj−1​−aj​∣)，且可以取到，因为：

  1. mmm如果比gcd⁡(∣ai−ai+1∣,⋯ ,∣aj−1−aj∣)\gcd(\left|a_i - a_{i + 1}\right|, \cdots, \left|a_{j - 1} - a_j\right|)gcd(∣ai​−ai+1​∣,⋯,∣aj−1​−aj​∣)大，那么一定存在∣ak−ak+1∣≢0mod  m  ⟺  ak−ak+1≠km(k∈Z)\left|a_k - a_{k + 1}\right| \not\equiv 0\mod m\iff a_k - a_{k + 1}\neq km(k\in\textbf{Z})∣ak​−ak+1​∣≡0modm⟺ak​−ak+1​=km(k∈Z)，矛盾。
  2. m=gcd⁡(∣ai−ai+1∣,⋯ ,∣aj−1−aj∣)m=\gcd(\left|a_i - a_{i + 1}\right|, \cdots, \left|a_{j - 1} - a_j\right|)m=gcd(∣ai​−ai+1​∣,⋯,∣aj−1​−aj​∣)时，任意两个数ak−ah=(ak−ak+1)+(ak+1−ak+2)+⋯+(ah−1−ah)=(k1+k2+⋯kh−k)ma_k - a_h = (a_k - a_{k + 1}) + (a_{k + 1} - a_{k + 2}) + \cdots + (a_{h - 1} - a_h) = (k_1 + k_2 + \cdots k_{h - k})mak​−ah​=(ak​−ak+1​)+(ak+1​−ak+2​)+⋯+(ah−1​−ah​)=(k1​+k2​+⋯kh−k​)m，所以满足条件。

根据以上分析，确定区间就可以直接求出mmm。这个时候有两种解决方法：

  1. 利用倍增，每个数往后倍增直到m=1m=1m=1，时间复杂度O(nlog⁡nlog⁡max⁡ai)O(n\log n\log \max a_i)O(nlognlogmaxai​)。利用st表可以做到O(nlog⁡max⁡ai+nlog⁡n)O(n\log\max a_i + n\log n)O(nlogmaxai​+nlogn)。
  2. 利用baka's trick进行双指针：每一时刻都有三个指针：l,r,midl, r, midl,r,mid，其中mid∈[l,r]mid\in [l, r]mid∈[l,r]，并且每一时刻[l,mid],[l+1,mid],⋯ ,[mid−1,mid][l, mid], [l + 1, mid], \cdots, [mid - 1, mid][l,mid],[l+1,mid],⋯,[mid−1,mid]的贡献已经处理好。当lll要跨越midmidmid的时候，将midmidmid设为rrr，并让lll从rrr倒序遍历回来，处理好新的[l,mid],[l+1,mid],⋯ ,[mid−1,mid][l, mid], [l + 1, mid], \cdots, [mid - 1, mid][l,mid],[l+1,mid],⋯,[mid−1,mid]的贡献。通过这样反复横跳，可以实现无删的双指针（只要单调且可加就可以双指针）。由于rrr总共动nnn次，midmidmid是单调增加的，也最多总共动nnn格，而lll除了本身要动的nnn下，最多再把midmidmid走的路径走一遍，也是只要动O(n)O(n)O(n)下。故要计算的次数还是O(n)O(n)O(n)的。这样时间复杂度就是O(nlog⁡max⁡ai)O(n\log\max a_i)O(nlogmaxai​)。
