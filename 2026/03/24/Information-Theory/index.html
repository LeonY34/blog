信息论

信息熵（Entropy）

定义

对于一个分布XXX，我们想要衡量它的信息量H(X)H(X)H(X)，作以下要求：

  • H(X)H(X)H(X)仅与XXX的概率分布有关，和具体的xxx无关；
  • H(X)H(X)H(X)关于概率连续（概率微小变化，信息量也发生微小变化）；
  • 对于独立分布XXX和YYY，总共的信息量应该为两者之和；
  • 概率越小，信息量越大。

可以得出H(X)H(X)H(X)的唯一形式为：

H(X)=−∑p(x)log⁡p(x)H(X) = -\sum p(x)\log p(x) H(X)=−∑p(x)logp(x)

也就是各个事件的信息量−log⁡p-\log p−logp按照ppp加权求和。

按照底数不同，单位也不同。比如说以222为底，单位是bit\mathrm{bit}bit；以eee为底，单位是nat\mathrm{nat}nat。

香农熵的公理化推导（Claude）

目标

寻找一个函数 H(p1,p2,…,pn)H(p_1, p_2, \ldots, p_n)H(p1​,p2​,…,pn​)，用来度量概率分布 (p1,…,pn)(p_1, \ldots, p_n)(p1​,…,pn​) 的"不确定性"，要求它满足三条自然公理。

三条公理

公理 1（连续性）

H(p1,p2,…,pn)H(p_1, p_2, \ldots, p_n)H(p1​,p2​,…,pn​) 是各 pip_ipi​ 的连续函数。

概率的微小扰动不应导致不确定性的突变。

公理 2（对称性 + 均匀分布单调性）

对于均匀分布 H(1n,…,1n)≜f(n)H\left(\frac{1}{n}, \ldots, \frac{1}{n}\right) \triangleq f(n)H(n1​,…,n1​)≜f(n)，要求 f(n)f(n)f(n) 关于 nnn 严格单调递增。

等可能的结果越多，不确定性越大。

公理 3（递归分解性 / 链式法则）

若将某个结果进一步细分，总不确定性应满足：

H(1n,…,1n)=H(kn,n−kn)+kn H(1k,…,1k)⏟k 个+n−kn H(1n−k,…,1n−k)⏟n−k 个H\left(\frac{1}{n}, \ldots, \frac{1}{n}\right) = H\left(\frac{k}{n}, \frac{n-k}{n}\right) + \frac{k}{n}\,H\underbrace{\left(\frac{1}{k}, \ldots, \frac{1}{k}\right)}_{k\text{ 个}} + \frac{n-k}{n}\,H\underbrace{\left(\frac{1}{n-k}, \ldots, \frac{1}{n-k}\right)}_{n-k\text{ 个}} H(n1​,…,n1​)=H(nk​,nn−k​)+nk​Hk 个(k1​,…,k1​)​​+nn−k​Hn−k 个(n−k1​,…,n−k1​)​​

更一般地，对任意分布，粗粒化后再细化的不确定性之和等于直接计算的不确定性：

H(p1,…,pn)=H(p1+p2, p3,…,pn)+(p1+p2) H ⁣(p1p1+p2,p2p1+p2)H(p_1,\ldots,p_n) = H(p_1+p_2,\, p_3,\ldots,p_n) + (p_1+p_2)\,H\!\left(\frac{p_1}{p_1+p_2},\frac{p_2}{p_1+p_2}\right) H(p1​,…,pn​)=H(p1​+p2​,p3​,…,pn​)+(p1​+p2​)H(p1​+p2​p1​​,p1​+p2​p2​​)

分两步获得的信息量，等于一步获得的信息量。

推导过程

第一步：确定 f(n) 的形式

由公理 3，对均匀分布 n=kmn = kmn=km（k,mk, mk,m 为正整数），将 kmkmkm 个等概率事件先分成 kkk 组，每组 mmm 个：

f(km)=f(k)+f(m)f(km) = f(k) + f(m) f(km)=f(k)+f(m)

这是经典的柯西函数方程：f(km)=f(k)+f(m)f(km) = f(k) + f(m)f(km)=f(k)+f(m)。

结合公理 1（连续性）和公理 2（严格单调递增），其唯一解为：

f(n)=Clog⁡n,C>0\boxed{f(n) = C \log n, \quad C > 0} f(n)=Clogn,C>0​

证明要点：令 g(x)=f(ex)g(x) = f(e^x)g(x)=f(ex)，则 g(x+y)=g(x)+g(y)g(x+y)=g(x)+g(y)g(x+y)=g(x)+g(y)，连续解唯一为 g(x)=Cxg(x)=Cxg(x)=Cx，故 f(n)=Clog⁡nf(n)=C\log nf(n)=Clogn。

第二步：从均匀分布推广到有理数概率

设 pi=niNp_i = \frac{n_i}{N}pi​=Nni​​，其中 nin_ini​ 为正整数，N=∑iniN = \sum_i n_iN=∑i​ni​。

考虑将 NNN 个等概率事件分组：第 iii 组有 nin_ini​ 个。由公理 3：

f(N)=H(p1,…,pk)+∑i=1kpi⋅f(ni)f(N) = H(p_1, \ldots, p_k) + \sum_{i=1}^k p_i \cdot f(n_i) f(N)=H(p1​,…,pk​)+i=1∑k​pi​⋅f(ni​)

即：

Clog⁡N=H(p1,…,pk)+∑i=1kpi⋅Clog⁡niC\log N = H(p_1,\ldots,p_k) + \sum_{i=1}^k p_i \cdot C\log n_i ClogN=H(p1​,…,pk​)+i=1∑k​pi​⋅Clogni​

解出 HHH：

H(p1,…,pk)=Clog⁡N−C∑i=1kpilog⁡niH(p_1,\ldots,p_k) = C\log N - C\sum_{i=1}^k p_i \log n_i H(p1​,…,pk​)=ClogN−Ci=1∑k​pi​logni​

=C∑i=1kpilog⁡N−C∑i=1kpilog⁡ni= C\sum_{i=1}^k p_i \log N - C\sum_{i=1}^k p_i \log n_i =Ci=1∑k​pi​logN−Ci=1∑k​pi​logni​

第三步：推广到实数概率

对任意实数概率 pi∈[0,1]p_i \in [0,1]pi​∈[0,1]，取有理数序列 pi(m)→pip_i^{(m)} \to p_ipi(m)​→pi​，由公理 1（连续性）：

H(p1(m),…,pk(m))→H(p1,…,pk)H(p_1^{(m)}, \ldots, p_k^{(m)}) \to H(p_1, \ldots, p_k) H(p1(m)​,…,pk(m)​)→H(p1​,…,pk​)

而左边对所有有理点均等于 −C∑pi(m)log⁡pi(m)-C\sum p_i^{(m)} \log p_i^{(m)}−C∑pi(m)​logpi(m)​，取极限得结论对全体实数概率成立。

最终结论

满足三条公理的函数唯一（至多相差正常数 CCC）：

H(p1,…,pn)=−C∑i=1npilog⁡pi\boxed{H(p_1, \ldots, p_n) = -C \sum_{i=1}^n p_i \log p_i} H(p1​,…,pn​)=−Ci=1∑n​pi​logpi​​

  • 取 C=1C=1C=1，对数底为 2 → 单位 bit
  • 取 C=1C=1C=1，对数底为 eee → 单位 nat
  • 常数 CCC 的选取仅影响单位，不影响结构

Joint Entropy

H(X,Y)=−∑p(x,y)log⁡p(x,y)H(X, Y) = -\sum p(x, y)\log p(x, y) H(X,Y)=−∑p(x,y)logp(x,y)

可以得到：

  • H(X,X)=H(X)H(X, X) = H(X)H(X,X)=H(X)；
  • 如果X,YX, YX,Y独立，H(X,Y)=H(X)+H(Y)H(X, Y) = H(X) + H(Y)H(X,Y)=H(X)+H(Y)。

可以定义一般的Joint Entropy：

H(X1,X2,⋯ ,Xn)=−E[log⁡p(X1,X2,⋯ ,Xn)]H(X_1, X_2, \cdots, X_n) = -\mathbf E[\log p(X_1, X_2, \cdots, X_n)] H(X1​,X2​,⋯,Xn​)=−E[logp(X1​,X2​,⋯,Xn​)]

Conditional Entropy

H(X∣Y)=−E[log⁡p(X∣Y)]H(X\mid Y) = -\mathbf E[\log p(X\mid Y)] H(X∣Y)=−E[logp(X∣Y)]

可以得到

H(X∣Y)+H(Y)=−E[log⁡p(X∣Y)]−E[log⁡p(Y)]=−E[log⁡p(X)]=H(X)\begin{aligned} H(X\mid Y) + H(Y) &= -\mathbf E[\log p(X\mid Y)] - \mathbf E[\log p(Y)] \\ &= -\mathbf E[\log p(X)] \\ &= H(X) \end{aligned}H(X∣Y)+H(Y)​=−E[logp(X∣Y)]−E[logp(Y)]=−E[logp(X)]=H(X)​

Kullback-Leibler (KL) distance (Relative Entropy)

对于总体XXX的两个概率密度分布p(x)p(x)p(x)和q(x)q(x)q(x)，定义KL散度为

D(p∥q)=∑p(x)log⁡p(x)q(x)D(p\parallel q) = \sum p(x)\log \frac{p(x)}{q(x)} D(p∥q)=∑p(x)logq(x)p(x)​

KL散度具有非对称性。
