现在来考虑一个确定的policy π\piπ，产生的随机过程。StS_tSt​表示ttt时刻在的state，RtR_tRt​表示ttt时刻到达StS_tSt​的时候获得的reward，AtA_tAt​表示ttt时刻到t+1t+1t+1时刻用的决策。可以表示为St→Rt+1AtSt+1→⋯S_t \xrightarrow[R_{t+1}]{A_t} S_{t+1} \rightarrow \cdotsSt​At​Rt+1​​St+1​→⋯。

令GtG_tGt​表示从ttt时刻的状态出发，trajectory总共的return。那么就有

Gt=Rt+1+γRt+2+γ2Rt+3+⋯G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots Gt​=Rt+1​+γRt+2​+γ2Rt+3​+⋯

令vπ(s)v_\pi(s)vπ​(s)表示在sss这个state出发，期望能得到的return。也就有

vπ(s)=E[Gt∣St=s]=E[Rt+1+γGt+1∣St=s]=E[Rt+1+γvπ(St+1)∣St=s]=∑aπ(a∣s)[∑rp(r∣s,a)⋅r+γ∑s′p(s′∣s,a)⋅vπ(s′)]\begin{aligned} v_\pi(s) &= \mathbb E[G_t | S_t = s]\\ &= \mathbb E[R_{t + 1} + \gamma G_{t + 1} | S_t = s] \\ &= \mathbb E[R_{t + 1} + \gamma v_\pi(S_{t + 1}) | S_t = s]\\ &= \sum_{a} \pi(a | s) [\sum_{r} p(r | s, a) \cdot r + \gamma\sum_{s'} p(s' | s, a) \cdot v_\pi(s')] \end{aligned}vπ​(s)​=E[Gt​∣St​=s]=E[Rt+1​+γGt+1​∣St​=s]=E[Rt+1​+γvπ​(St+1​)∣St​=s]=a∑​π(a∣s)[r∑​p(r∣s,a)⋅r+γs′∑​p(s′∣s,a)⋅vπ​(s′)]​

令rπ(s)r_\pi(s)rπ​(s)表示π\piπ这个policy之下，在sss点出发走一步的期望reward，用pπ(s′∣s)p_\pi(s'|s)pπ​(s′∣s)表示在π\piπ这个policy之下，从sss点出发走一步到达s′s's′的概率，那么可以重写：

rπ(s)=∑aπ(a∣s)∑rr⋅p(r∣a,s)pπ(s′∣s)=∑aπ(a∣s)∑s′p(s′∣s,a)vπ(s)=rπ(s)+γ∑s′pπ(s′∣s)⋅vπ(s′)\begin{aligned} r_\pi(s) &= \sum_{a} \pi(a|s) \sum_{r} r\cdot p(r|a, s)\\ p_\pi(s'|s) &= \sum_a \pi(a|s) \sum_{s'} p(s'|s, a)\\ v_\pi(s) &= r_\pi(s) + \gamma \sum_{s'}p_\pi(s'|s)\cdot v_\pi(s') \end{aligned}rπ​(s)pπ​(s′∣s)vπ​(s)​=a∑​π(a∣s)r∑​r⋅p(r∣a,s)=a∑​π(a∣s)s′∑​p(s′∣s,a)=rπ​(s)+γs′∑​pπ​(s′∣s)⋅vπ​(s′)​

然后就可以写成矩阵形式：

vπ=rπ+γPπvπv_\pi = r_\pi + \gamma P_\pi v_\pi vπ​=rπ​+γPπ​vπ​

其中Pπ,ij=pπ(sj∣si)P_{\pi, ij} = p_\pi(s_j|s_i)Pπ,ij​=pπ​(sj​∣si​)。这个就是Bellman Equation。vvv向量叫做state value。

但这个复杂度是O(∣S∣3)O(\left|\mathcal S\right|^3)O(∣S∣3)。

为了快速求解，可以使用迭代法：

可以得出{vn}\{v_{n}\}{vn​}是一个Cauchy序列，收敛到v∗v^*v∗，有v∗=rπ+γPπv∗v^* = r_\pi + \gamma P_\pi v^*v∗=rπ​+γPπ​v∗。

这个迭代法复杂度就变成了O(∣S∣2log⁡precision)O(\left|\mathcal S\right|^2 \log \text{precision})O(∣S∣2logprecision)。

Action value: qπ(s,a)=E[Gt∣St=s,At=a]q_\pi(s, a) = \mathbb E[G_t | S_t = s, A_t = a]qπ​(s,a)=E[Gt​∣St​=s,At​=a]。

可以写成

vπ(s)=∑aπ(a∣s)qπ(s,a)v_\pi(s) = \sum_{a} \pi(a|s) q_\pi(s,a) vπ​(s)=a∑​π(a∣s)qπ​(s,a)

Optimal State Values and Bellman Optimality Equation

现在研究BOE(Bellman Optimality Equation)。之前的Bellman Equation的目标是对于一个确定的策略，解出state value/action value，也就是说合法的state value都应该满足Bellman Equation。现在我们想建立另一个equation，使得只有最优的state value能够满足。

我们现在假设v(s)v(s)v(s)是一个变量，满足：

v(s)=max⁡π∑aπ(a∣s)q(s,a)v(s) = \max_\pi \sum_a \pi(a|s) q(s,a) v(s)=πmax​a∑​π(a∣s)q(s,a)

其中

q(s,a)=∑rr⋅p(r∣s,a)+∑s′v(s′)⋅p(s′∣s,a)q(s,a) = \sum_r r\cdot p(r|s,a) + \sum_{s'} v(s')\cdot p(s'|s,a) q(s,a)=r∑​r⋅p(r∣s,a)+s′∑​v(s′)⋅p(s′∣s,a)

我们想要知道四件事情：

  • 这个方程是否有解；
  • 这个方程解是否唯一；
  • 怎么找到这个方程的解；
  • 这个方程的解就是最优的state value吗。

首先可以得出

v(s)≤max⁡π((max⁡aq(s,a))∑aπ(a∣s))=max⁡aq(s,a)v(s) \leq \max_\pi \left(\left(\max_a q(s,a)\right)\sum_a \pi(a|s) \right) = \max_a q(s,a) v(s)≤πmax​((amax​q(s,a))a∑​π(a∣s))=amax​q(s,a)

所以说v(s)v(s)v(s)的解就是最大的q(s,a)q(s,a)q(s,a)。

Value Iteration and Policy Iteration

Value Iteration: 利用前一章说的方法：

πn+1=arg max⁡π(rπ+γPπvn)vn+1=rπn+1+γPπn+1vn\begin{aligned} \pi_{n+1} &= \argmax_{\pi} \left(r_\pi + \gamma P_\pi v_n\right)\\ v_{n+1} &= r_{\pi_{n+1}} + \gamma P_{\pi_{n+1}}v_n \end{aligned}πn+1​vn+1​​=πargmax​(rπ​+γPπ​vn​)=rπn+1​​+γPπn+1​​vn​​

但是π\piπ难以枚举。我们利用之前推出的elementwise贪心公式：

可以得到π\piπ取贪心策略的时候，可以得到最大值。这样只需要枚举所有的a∈Aa\in \mathcal Aa∈A即可。

复杂度O(∣A∣∣S∣2log⁡precision)O(\left|\mathcal A\right|\left|\mathcal S\right|^2\log \text{precision})O(∣A∣∣S∣2logprecision)。其中∣S∣2\left|S\right|^2∣S∣2不一定吃的满，因为PPP矩阵可能是稀疏的。

Policy Iteration：先确认一个初始Policy，然后利用Bellman Equation迭代出当前对应的vvv，然后再利用Value Iteration的方法迭代一步，得到新的policy。这样的好处是，每次policy对应的vvv都会比原先的vvv好一点。

Truncated Policy Iteration：把Policy Iteration改成不一定迭代到Bellman Equation收敛，也不像Value Iteration一样只迭代一下，而是迭代kkk次，取一个折中。
