一些有意思的小不等式。

Abel恒等式

∑i=1naibi=∑i=1n−1(ai−ai+1)Bi+anBn\sum_{i=1}^n a_ib_i = \sum_{i=1}^{n-1} (a_i - a_{i+1}) B_i + a_n B_n i=1∑n​ai​bi​=i=1∑n−1​(ai​−ai+1​)Bi​+an​Bn​

其中Bi=∑j=1ibjB_i = \sum_{j=1}^i b_jBi​=∑j=1i​bj​。

!!! note 证明
证明可以用数学归纳法。

排序不等式

对于任意两个单调不降序列a1≤a2≤⋯≤ana_1\leq a_2\leq \cdots\leq a_na1​≤a2​≤⋯≤an​以及b1≤b2≤⋯≤bnb_1\leq b_2\leq\cdots\leq b_nb1​≤b2​≤⋯≤bn​，对于任意一个1,2,⋯ ,n1,2,\cdots, n1,2,⋯,n的排列i1,i2,⋯ ,ini_1, i_2, \cdots, i_ni1​,i2​,⋯,in​，有：

∑j=1najbj≥∑j=1najbij\sum_{j=1}^n a_jb_j \geq \sum_{j=1}^n a_jb_{i_j} j=1∑n​aj​bj​≥j=1∑n​aj​bij​​

!!! note 证明
证明如下：
$$\begin{aligned}
&\text{LHS} - \text{RHS} = \sum_{j=1}^n a_j(b_j - b_{i_j})\
=& \sum_{j=1}^{n-1} (a_j - a_{j+1})\sum_{k=1}^j (b_k - b_{i_k}) + a_n\sum_{k=1}^n (b_k - b_{i_k})\
\end{aligned}$$

由于$a_j\leq a_{j+1}$且$\sum_{k=1}^j(b_k - b_{i_k}) = \sum_{k=1}^j b_k - \sum_{k=1}^j b_{i_k} \leq 0$，所以$(a_j-a_{j+1})\sum_{k=1}^j(b_k - b_{i_k}) \leq 0$，所以第一项$\geq 0$；
而第二项为$a_n\left(\sum_{k=1}^n b_k - \sum_{k=1}^n b_{i_k}\right) = a_n \cdot 0 = 0$，所以$\text{LHS} - \text{RHS} \geq 0$，得证。

!!! tip 反方向的排序不等式
把bbb序列调整为b1≥b2≥⋯≥bnb_1\geq b_2\geq \cdots\geq b_nb1​≥b2​≥⋯≥bn​，证明部分第一部分改为小于0，第二部分依旧等于0，可以证明反方向的排序不等式。

Inequality of arithmetic-geometric means

对于正数a1,a2,⋯ ,ana_1, a_2, \cdots, a_na1​,a2​,⋯,an​，有

a1+a2+⋯+ann≥a1a2⋯ann\frac{a_1 + a_2 + \cdots + a_n}{n} \geq \sqrt[n]{a_1a_2\cdots a_n} na1​+a2​+⋯+an​​≥na1​a2​⋯an​​

!!! note 证明
令A=a1a2⋯annA = \sqrt[n]{a_1 a_2 \cdots a_n}A=na1​a2​⋯an​​，构造新的序列ai′=aiAa_i' = \frac{a_i}{A}ai′​=Aai​​，则原不等式成立  ⟺  \iff⟺新不等式成立：
$$\frac{a_1’ + a_2’ + \cdots + a_n’}{n} \geq 1$$
随便取两个正数b1,b2b_1, b_2b1​,b2​满足a1′=b1b2a_1' = \frac{b_1}{b_2}a1′​=b2​b1​​，然后再递推求得b3=b2a2′b_3 = \frac{b_2}{a_2'}b3​=a2′​b2​​，b4=b3a3′b_4 = \frac{b_3}{a_3'}b4​=a3′​b3​​ ,…，bn=bn−1an−1′b_n = \frac{b_{n-1}}{a_{n-1}'}bn​=an−1′​bn−1​​。则可以得到：

$$\begin{cases}
a_i' = \frac{b_i}{b_{i+1}} & 1 \leq i \leq n - 1\\
a_n' = \frac{1}{a_1'a_2'\cdots a_{n-1}'} = \frac{b_n}{b_1}
\end{cases}$$

这时可以构造两个序列：$c_i = b_i$和$d_i = \frac{1}{b_i}$。则根据**排序不等式**：
$$\frac{a_1' + a_2' + \cdots + a_n'}{n} = \frac{1}{n}\sum c_i d_j \geq \frac{1}{n} \sum c_i d_i = \frac{1}{n} \cdot n = 1$$
