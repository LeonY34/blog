不过我们视此为作弊，不讨论。

我们来寻找优化方法。

首先，我们来介绍一下新角色：二进制。

我们平时写数，以及电脑给我们呈现的，大多都是十进制的。

我们知道，一个数在十进制表示下的规则是满十进一，每一位上的数都是 0...90...90...9 中的一个。

我们板板手指头想想，发现如果一个正整数只有一位不为零，从右往左数第 iii 位是 jjj 的话，那么这个数就是 j×10ij\times {10}^ij×10i 。

每个十进制数都可以拆分成若干个如上所说的数。比如

6012=6000+10+2=6×103+1×101+2×1006012 = 6000 + 10 + 2 = 6\times{10}^3 + 1\times{10}^1 + 2\times{10}^0 6012=6000+10+2=6×103+1×101+2×100

但这样拆分好像非常复杂，没个鸟屎用。

这个时候，二进制就出场了。

类比十进制，二进制是满二进一，每一位上的数不是 000 就是 111 。

可见，二进制要简洁的多，所以计算机运算都是使用二进制的。

类比一下，发现如果一个正整数（二进制表示）只有一位不为零，从右往左数第 iii 位是 111 的话，那么这个数就是 2i2^i2i 。

这个比十进制简洁多了。我们不妨用 (x)2(x)_2(x)2​ 表示 xxx 是一个二进制表示。

那么每个二进制数都能拆分，比如

(1011)2=(1000)2+(10)2+(1)2=23+21+20(1011)_2 = (1000)_2 + (10)_2 + (1)_2 = 2^3 + 2^1 + 2^0 (1011)2​=(1000)2​+(10)2​+(1)2​=23+21+20

而一个数 xxx 最多能拆成几个 2n2^n2n 呢？很显然是 O(log⁡x)O(\log x)O(logx) 的。

于是我们可以将瓶颈 bbb 进行拆分，那么答案 abmod  pa^b\mod pabmodp 就是

ab=a∑i=1kBi=∏i=1kaBia^b = a^{\sum_{i=1}^{k} B_i} = \prod_{i=1}^{k} a^{B_i} ab=a∑i=1k​Bi​=i=1∏k​aBi​

其中

b=∑i=1kBi,∀i∈[1,k],Bi=2ri,∀j∈[1,k],i≠j,ri≠rjb = \sum_{i=1}^{k} B_i, \forall i\in [1,k], B_i = 2^{r_i} ,\forall j\in [1,k], i\neq j,r_i\neq r_j b=i=1∑k​Bi​,∀i∈[1,k],Bi​=2ri​,∀j∈[1,k],i=j,ri​=rj​

显然 k<log⁡2b,ri≤log⁡2bk< \log_2 b, r_i\leq \log_2 bk<log2​b,ri​≤log2​b ，那我们只需要知道 a20,a21,...,a2⌊log⁡2b⌋a^{2^0}, a^{2^1}, ..., a^{2^{\lfloor\log_2 b\rfloor}}a20,a21,...,a2⌊log2​b⌋ 就行了。

很容易发现 a2i=(a2i)2,a20=aa^{2^i} = (a^{2^i})^2, a^{2^0} = aa2i=(a2i)2,a20=a 。那就可以在 O(log⁡b)O(\log b)O(logb) 内求 aBia^{B_i}aBi​ 了，连乘，由于 k<log⁡2bk<\log_2 bk<log2​b ，也可以在 O(log⁡b)O(\log b)O(logb) 内求出。
