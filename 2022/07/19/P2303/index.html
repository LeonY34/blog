P2303 [SDOI2012] Longge 的问题

idea:

推式子。

解决方案：

直接开推：

∑i=1ngcd⁡(i,n)=∑d∣nd∑d∣in[gcd⁡(i,n)=d]=∑d∣nd∑i=1nd[gcd⁡(i,nd)=1]=∑d∣nd⋅φ(nd)\sum_{i=1}^n\gcd(i,n) = \sum_{d\mid n}d\sum_{d\mid i}^n [\gcd(i,n)=d] = \sum_{d\mid n}d\sum_{i=1}^{\frac{n}{d}} [\gcd(i,\frac{n}{d})=1] = \sum_{d\mid n}d\cdot\varphi(\frac{n}{d}) i=1∑n​gcd(i,n)=d∣n∑​dd∣i∑n​[gcd(i,n)=d]=d∣n∑​di=1∑dn​​[gcd(i,dn​)=1]=d∣n∑​d⋅φ(dn​)

这个式子已经可以用了：我们求出 nnn 的所有质因子，然后 DfsDfsDfs 枚举 nnn 的因子即可。时间复杂度 O(n+k)O(\sqrt n + k)O(n​+k) 。 kkk 为 nnn 的因子数。由于 O(k)=O(n)O(k) = O(\sqrt n)O(k)=O(n​) ，时间复杂度是 O(n)O(\sqrt n)O(n​) 的。

然而我们可以再进一步优化（参考题解）

∑d∣nd⋅φ(nd)=∑d∣nnd⋅φ(d)=∑d∣nnd⋅d∏p∣d,p∈Pp−1p=n⋅∑d∣n∏p∣d,p∈Pp−1p\sum_{d\mid n}d\cdot\varphi(\frac{n}{d}) = \sum_{d\mid n}\frac{n}{d}\cdot\varphi(d) = \sum_{d\mid n}\frac{n}{d}\cdot d\prod_{p\mid d,p\in\mathbb{P}} \frac{p-1}{p} = n\cdot\sum_{d\mid n}\prod_{p\mid d,p\in\mathbb{P}} \frac{p-1}{p} d∣n∑​d⋅φ(dn​)=d∣n∑​dn​⋅φ(d)=d∣n∑​dn​⋅dp∣d,p∈P∏​pp−1​=n⋅d∣n∑​p∣d,p∈P∏​pp−1​

将 nnn ，ddd 分解：

n=∏i=1kpiai                     n = \prod_{i=1}^k p_i^{a_i}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ n=i=1∏k​piai​​                     

d=∏i=1kpibi(bi∈[0,ai])d = \prod_{i=1}^k p_i^{b_i}(b_i\in[0,a_i]) d=i=1∏k​pibi​​(bi​∈[0,ai​])

那么 ddd 的答案是：

resd=∏i=1kpi−1pi[bi≠0]res_d = \prod_{i=1}^k \frac{p_i-1}{p_i}[b_i\neq 0] resd​=i=1∏k​pi​pi​−1​[bi​=0]

那么可以发现，与 ddd 答案相同的其他数只需要包含相同的质因数即可，和个数无关。不妨设 ddd 有 ggg 个不同的质因子，第 iii 个质因子为 qiq_iqi​ 。对于和 ddd 一类的数答案的和为：

ansd=(∏i=1gqi−1qi)(∏i=1gapos(i))=∏i=1gqi−1qi⋅apos(i)ans_d = (\prod_{i=1}^g \frac{q_i-1}{q_i})(\prod_{i=1}^g a_{pos(i)}) = \prod_{i=1}^g \frac{q_i-1}{q_i}\cdot a_{pos(i)} ansd​=(i=1∏g​qi​qi​−1​)(i=1∏g​apos(i)​)=i=1∏g​qi​qi​−1​⋅apos(i)​

对于 nnn 的每个质因子，都可以有选和不选两种原则。故答案为：

∑(p1−1p1⋅a1)0/1⋅(p2−1p2⋅a2)0/1...(pk−1pk⋅ak)0/1\sum (\frac{p_1-1}{p_1}\cdot a_1)^{0/1}\cdot (\frac{p_2-1}{p_2}\cdot a_2)^{0/1}...(\frac{p_k-1}{p_k}\cdot a_k)^{0/1} ∑(p1​p1​−1​⋅a1​)0/1⋅(p2​p2​−1​⋅a2​)0/1...(pk​pk​−1​⋅ak​)0/1

只能意会。。。相当于 Σ\SigmaΣ 里面有 2n2^n2n 项。然后我们可以因式分解，答案为：

∏i=1k(pi−1pi⋅ai+1)\prod_{i=1}^k (\frac{p_i-1}{p_i}\cdot a_i +1) i=1∏k​(pi​pi​−1​⋅ai​+1)

其实很好理解，每个质因子都可以选和不选，选的话是前面一坨，不选是 111 ，乘开来刚好是 2n2^n2n 项。

用这个式子可以做到时间上 O(n)O(\sqrt n)O(n​) 的复杂度，空间上 O(1)O(1)O(1) 。
