P2155 [SDOI2008] 沙拉公主的困惑

idea:

推式子，转化为欧拉函数

解决方案：

根据题意写式子：

∑i=1n![gcd(i,m!)=1]    \sum_{i=1}^{n!} [gcd(i,m!)=1]\ \ \ \ i=1∑n!​[gcd(i,m!)=1]    

=∑i=1n![gcd(i%m!,m!)=1]=\sum_{i=1}^{n!} [gcd(i\%m!,m!)=1] =i=1∑n!​[gcd(i%m!,m!)=1]

=n!m!∑i=1m![gcd(i,m!)=1]  =\frac{n!}{m!}\sum_{i=1}^{m!}[gcd(i,m!)=1]\ \ =m!n!​i=1∑m!​[gcd(i,m!)=1]  

=n!m!φ(m!)                        =\frac{n!}{m!}\varphi(m!)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ =m!n!​φ(m!)                        

=n!m!∏pk∣m!,p∈Ppk(1−1p)   =\frac{n!}{m!}\prod_{p^k\mid m!,p\in\mathbb{P}} p^k(1-\frac{1}{p})\ \ \ =m!n!​pk∣m!,p∈P∏​pk(1−p1​)   

=n!∏p∣m!,p∈Pp−1p              =n!\prod_{p|m!,p\in\mathbb{P}} \frac{p-1}{p}\ \ \ \ \ \ \ \ \ \ \ \ \ \ =n!p∣m!,p∈P∏​pp−1​              

这个式子就可以处理了。需要注意的是， RRR 可能会很小，这时要上下同时约去 RRR 。
