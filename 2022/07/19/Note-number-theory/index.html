欧拉定理和欧拉函数

欧拉函数：

定义式：

φ(x)=∑i=1x[gcd⁡(i,x)=1]\varphi(x) = \sum_{i=1}^{x} [\gcd(i,x)=1] φ(x)=i=1∑x​[gcd(i,x)=1]

根据定义可证欧拉函数是积性函数。

  1. 筛法

很容易得出 φ(pk)=pk−pk−1    (p∈P)\varphi(p^k) = p^k-p^{k-1}\ \ \ \ (p\in\mathbb{P})φ(pk)=pk−pk−1    (p∈P) 。

进而得出 φ(pk)=p⋅φ(pk−1)    (p∈P)\varphi(p^k) = p\cdot\varphi(p^{k-1})\ \ \ \ (p\in\mathbb{P})φ(pk)=p⋅φ(pk−1)    (p∈P) 。

那么有当 x=p⋅y(p∈P)x=p\cdot y(p\in\mathbb{P})x=p⋅y(p∈P) 时有

φ(p⋅y)=φ(p)⋅φ(y)=(p−1)⋅φ(y)    (gcd⁡(p,y)=1)\varphi(p\cdot y) = \varphi(p)\cdot \varphi(y) = (p-1)\cdot \varphi(y)\ \ \ \ (\gcd(p,y)=1) φ(p⋅y)=φ(p)⋅φ(y)=(p−1)⋅φ(y)    (gcd(p,y)=1)

φ(p⋅y)=φ(pk⋅ypk−1)=φ(pk)⋅φ(ypk−1)=p⋅φ(pk−1)⋅φ(ypk−1)=p⋅φ(y)\varphi(p\cdot y) = \varphi(p^k\cdot \frac{y}{p^{k-1}}) = \varphi(p^k)\cdot\varphi(\frac{y}{p^{k-1}}) = p\cdot\varphi(p^{k-1})\cdot\varphi(\frac{y}{p^{k-1}}) = p\cdot \varphi(y) φ(p⋅y)=φ(pk⋅pk−1y​)=φ(pk)⋅φ(pk−1y​)=p⋅φ(pk−1)⋅φ(pk−1y​)=p⋅φ(y)

(gcd⁡(p,y)≠1,gcd⁡(pk,ypk−1)=1)(\gcd(p,y)\neq 1, \gcd(p^k, \frac{y}{p^{k-1}}) = 1) (gcd(p,y)=1,gcd(pk,pk−1y​)=1)

运用以上两个公式就可以线性筛了。

或者可以变换成各种形式用其他筛法。

ifgcd⁡(a,p)=1, aφ(p)≡1(mod p)if \gcd(a,p)=1,\ a^{\varphi(p)}\equiv 1(mod\ p) ifgcd(a,p)=1, aφ(p)≡1(mod p)

我有一个伪证：由于 aia^iai 与 ppp 互质，故在 [0,p−1][0,p-1][0,p−1] 中有 p−φ(p)p-\varphi(p)p−φ(p) 个数是不会出现的，其他数构成周期为 φ(p)\varphi(p)φ(p) 的循环，故 aφ(p)+1≡aa^{\varphi(p)+1}\equiv aaφ(p)+1≡a 。

欧拉定理可以用来求逆元。但我们更多情况下还是用费马小定理和扩展欧几里得算法求。

逆元：

当 a,pa,pa,p 互质时，存在唯一的 b (mod p)b\ (mod\ p)b (mod p) 使得 a⋅b≡1 (mod p)a\cdot b\equiv 1\ (mod\ p)a⋅b≡1 (mod p) 。记 bbb 为 1a\frac{1}{a}a1​ 或 a−1a^{-1}a−1 。

证明还不会。

欧拉定理求逆元： a−1≡aφ(p)−1 (mod p)a^{-1} \equiv a^{\varphi(p)-1}\ (mod\ p)a−1≡aφ(p)−1 (mod p) 。

可以用线性筛和快速幂求。

欧几里得算法和扩展欧几里得算法：

重要的公式：

gcd⁡(a,b)=gcd⁡(b,a mod b)\gcd(a,b) = \gcd(b,a\ mod\ b) gcd(a,b)=gcd(b,a mod b)

证明：令 gcd⁡(a,b)=d\gcd(a,b) = dgcd(a,b)=d ，则 a=x⋅da = x\cdot da=x⋅d ， b=y⋅db=y\cdot db=y⋅d ，且 gcd⁡(x,y)=1\gcd(x,y) = 1gcd(x,y)=1。

则 gcd⁡(a,b)=gcd⁡(x⋅d,y⋅d)=gcd⁡(y⋅d,(x mod y)⋅d)=gcd⁡(y⋅d,x⋅d mod y⋅d)=gcd⁡(b,a mod b)\gcd(a,b) = \gcd(x\cdot d, y\cdot d) = \gcd(y\cdot d, (x\ mod\ y)\cdot d) = \gcd(y\cdot d,x\cdot d\ mod\ y\cdot d) = \gcd(b,a\ mod\ b)gcd(a,b)=gcd(x⋅d,y⋅d)=gcd(y⋅d,(x mod y)⋅d)=gcd(y⋅d,x⋅d mod y⋅d)=gcd(b,a mod b) 。

反复运用这一公式求出 gcd⁡(a,b)\gcd(a,b)gcd(a,b) 就是欧几里得算法。递归边界为 b=0b=0b=0 ，时间复杂度为 O(log⁡min⁡(a,b))O(\log \min(a,b))O(logmin(a,b)) 。
